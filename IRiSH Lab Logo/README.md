# โลโก้ IRiSH Lab (ไฟล์ต้นฉบับ)

โฟลเดอร์นี้เก็บไฟล์โลโก้ต้นฉบับของ IRiSH — Intelligent Robot and Industrial
System Hub **ไฟล์รูปทั้งหมดในโฟลเดอร์นี้ไม่ได้ขึ้น git** (ถูกกันไว้ใน
`.gitignore`) มีแค่ README นี้ที่ขึ้นไป เพื่อบอกว่าต้นฉบับมีอะไรและหน้าเว็บใช้ไฟล์ไหน

ถ้า clone repo ใหม่แล้วไม่มีไฟล์รูปในโฟลเดอร์นี้ ถือว่าปกติ — ขอไฟล์ต้นฉบับจากแล็บ

## ไฟล์ที่มี

แต่ละแบบมีทั้ง `PNG/` (2049px) และ `SVG/`

| ไฟล์ | หน้าตา |
|---|---|
| `Logo_Square` | รูปสัญลักษณ์วงกลมอย่างเดียว |
| `Logo_Text` | รูปสัญลักษณ์ + "IRiSH" + ชื่อเต็มของแล็บ (สัดส่วน 2:1) |
| `Text_Square` | ข้อความอย่างเดียว ไม่มีรูปสัญลักษณ์ |

ท้ายชื่อไฟล์: `_B` = สีดำ, `_W` = สีขาว

## ไฟล์ที่หน้าเว็บใช้จริง

หน้าเว็บ **ไม่ได้อ่านจากโฟลเดอร์นี้** — คัดลอกไปไว้ที่ `public/brand/` แล้ว

| ใช้ที่ | ไฟล์ในเว็บ | มาจาก |
|---|---|---|
| หน้าเข้าสู่ระบบ | `public/brand/irish-logo-text.svg` | `SVG/Logo_Text_B.svg` |
| แถบเมนู (ทั้งตอนขยายและยุบ) | `public/brand/irish-mark.svg` | `SVG/Logo_Square_B.svg` |
| ไอคอนแท็บเบราว์เซอร์ | `src/app/icon.svg` | `SVG/Logo_Square_B.svg` + กฎสลับสีตามธีม |

ถ้าแล็บเปลี่ยนโลโก้ ให้คัดลอกไฟล์ใหม่ทับไฟล์ใน `public/brand/` ด้วย

## ข้อควรรู้ก่อนเปลี่ยนไฟล์

- **ใช้ SVG ไม่ใช้ PNG** — คมทุกขนาดและเล็กกว่ามาก (SVG 24–50 KB เทียบ PNG
  250–350 KB)
- **ไฟล์ `_W` (สีขาว) มีสี่เหลี่ยมพื้นดำฝังอยู่ ไม่ใช่พื้นใส** — ใช้ในโหมดมืดแล้ว
  จะเห็นเป็นกล่องดำ หน้าเว็บจึงใช้ไฟล์ `_B` อย่างเดียว แล้วกลับสีด้วย CSS
  (`.brand-logo` ใน `src/app/globals.css`)
- **ห้ามใช้ CSS ตัวพิมพ์ใหญ่กับชื่อแล็บ** — `uppercase` เปลี่ยน "IRiSH" เป็น
  "IRISH" ตัว i เล็กคือส่วนหนึ่งของชื่อ
