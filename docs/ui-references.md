# UI references

Outside sites to look at for UI and motion ideas. Add a line under each entry
saying what to take from it.

## Motion

- [Motion Reference — Takayu Studio](https://motion-reference.takayustudio.jp/)
  (saved 2026-10-12) — 782 named motions, each with a category, a duration in
  milliseconds and a line describing what the eye actually sees: enter/exit,
  move, scale, rotate, bounce and list/grid. Take the timings from it when
  choosing a transition. It names the intent rather than handing over a
  cubic-bezier, which is what makes a modal, a card and a list in this app
  move like one thing. In Japanese; the durations and the categories read
  without it.
